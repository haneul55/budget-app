# 사진 가계부 (budget_app)

영수증이나 쇼핑앱 결제 화면 사진으로 지출을 기록하는 안드로이드 가계부 앱입니다. Flutter로 만들고, 데이터는 폰 안(SQLite)에만 저장합니다.

## 지금 되는 것 (1단계)

- 홈: 월 선택, 이번 달 총지출, 카테고리별 누적 금액과 비율
- 카테고리 상세: 그 달의 결제 내역 목록, 누르면 수정·삭제
- 내역 직접 입력: 품목, 금액, 날짜, 카테고리, 구매처, 메모
- 카테고리 관리: 추가, 이름·아이콘·색상 변경, 삭제(내역은 미분류로 이동), 드래그로 순서 변경
- 기본 카테고리 7개: 식비, 카페/간식, 쇼핑, 생활/마트, 교통, 문화/여가, 기타

## 사진으로 자동 기입 (2단계)

- `+ 내역 추가` → 사진·캡처 불러오기 / 영수증 촬영 / 직접 입력
- 기기 안에서 글자를 읽고(ML Kit, 사진이 밖으로 나가지 않음) 규칙으로 품목·금액·날짜·구매처를 찾음
- 카테고리는 키워드 규칙으로 자동 분류 (예: '니트' → 쇼핑, '스타벅스' → 카페/간식)
- 저장 전 확인 화면에서 품목·금액·날짜·카테고리를 고치고, 항목을 빼거나 추가할 수 있음
- 자동 분류와 다르게 고른 카테고리는 기억해서 다음부터 그 카테고리로 분류
- 카테고리 관리에서 카테고리마다 분류 키워드를 추가·삭제
- 저장한 내역을 누르면 원본 사진이 함께 보이고, 사진을 누르면 확대

규칙 코드: `lib/recognition/receipt_parser.dart`(글자 해석), `lib/recognition/category_classifier.dart`(분류)

## 그래프와 월별 기록 (3단계)

- 홈 화면에 그 달의 날짜별 쓴 돈 꺾은선 그래프 (일별 / 누적 전환, 점을 누르면 금액 표시)
- 오른쪽 위 막대 아이콘 → 월별 기록: 최근 12개월 막대 그래프, 월 평균, 지난달 대비 증감
- 월별 기록에서 달을 누르면 홈 화면이 그 달로 이동
- 오른쪽 위 달력 아이콘 → 한 달 달력: 칸마다 그날 쓴 돈과 카테고리 색 점, 칸을 누르면 커지면서 그날 내역·카테고리·하루 합계 표시

## 앱 디자인

- 크림색 바탕, 피치색 포인트, 진한 회색 글자의 따뜻한 색 조합 (`lib/ui/app_theme.dart`의 `AppColors`에서 한 번에 바꿀 수 있음)
- 카테고리 색도 따뜻한 파스텔 톤으로 바꿈 (기존에 설치한 앱은 DB v3 업데이트 때 자동으로 새 색으로 바뀜)
- 달력은 피치색 요일 머리줄, 얇은 회색 칸선, 오른쪽 위 날짜 숫자, 피치색 금액 칩, 앞뒤 달 날짜는 흐리게

## Windows에서 실행하기

1. [Flutter 설치 안내](https://docs.flutter.dev/get-started/install/windows/mobile)를 따라 Flutter SDK와 Android Studio를 설치합니다.
2. 명령 프롬프트에서 `flutter doctor`를 실행해 빨간 X가 없는지 확인합니다. (`flutter doctor --android-licenses`로 라이선스 동의)
3. 안드로이드 폰에서 개발자 옵션과 USB 디버깅을 켜고 PC에 연결합니다. (또는 Android Studio의 에뮬레이터 사용)
4. 이 폴더에서:
   ```
   flutter pub get
   flutter run
   ```
5. 테스트: `flutter test`

## 폴더 구조

```
lib/
  main.dart                 앱 시작, 테마, 한국어 설정
  data/models.dart          Category, Expense 데이터 구조
  data/database.dart        SQLite 테이블과 조회·저장 함수
  data/category_icons.dart  고를 수 있는 아이콘·색상 목록
  state/providers.dart      화면에 데이터를 공급하는 Riverpod provider
  ui/                       화면들
test/                       DB·화면 테스트
```

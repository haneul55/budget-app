# 아이폰에서 시험해 보기 (Mac 없이, Windows만으로)

아이폰 앱은 원래 **Mac 컴퓨터의 Xcode**로만 만들 수 있습니다. 그래서 이 저장소는
GitHub가 빌려주는 Mac에서 앱 파일을 대신 만들도록 설정해 두었습니다.
안드로이드 쪽은 바뀐 게 없고, 지금처럼 `flutter run`으로 그대로 쓰면 됩니다.

<br>

## 방법 비교

| 방법 | 비용 | 장점 | 단점 |
|---|---|---|---|
| **① GitHub Actions + Sideloadly (추천)** | 무료 | Mac·유료 계정 없이 바로 가능 | 7일마다 PC에 연결해 다시 설치, 무료 Apple ID는 앱 3개까지 |
| ② 유료 Apple 개발자 계정 + TestFlight | 연 99달러 (한국 약 13만 원) | 케이블 없이 TestFlight 앱으로 설치, 90일 유지, 앱스토어 출시도 가능 | 비용, 인증서 설정이 조금 복잡 |
| ③ 클라우드 Mac 대여 (MacinCloud 등) + Xcode | 시간당 약 1~2달러부터 | 진짜 Mac 화면에서 Xcode 사용 | 원격 Mac에 아이폰을 USB로 꽂을 수 없어 설치가 번거로움 |

먼저 ①로 무료로 시험해 보고, 앱스토어에 내거나 친구에게도 나눠 주고 싶어지면 ②로 넘어가는 걸 추천합니다.

<br>

## ① 무료로 설치하기

### 1. 앱 파일(.ipa) 받기

1. GitHub 저장소 페이지 → 위쪽 **Actions** 탭 → 왼쪽 **iOS 빌드**를 누릅니다.
2. `main`에 코드를 올리면 자동으로 만들어집니다. 직접 만들려면 오른쪽 **Run workflow** 버튼을 누릅니다.
3. 초록 체크(약 10~20분 걸림)가 뜬 실행을 열고, 맨 아래 **Artifacts**의
   `budget_app-ios-unsigned`를 내려받아 압축을 풀면 `budget_app-unsigned.ipa`가 나옵니다.

### 2. Windows에 준비물 설치 (처음 한 번)

1. **iTunes**와 **iCloud**를 설치합니다. 마이크로소프트 스토어 버전이 아니라
   애플 홈페이지에서 받는 **웹 설치 버전**이어야 Sideloadly가 인식합니다.
2. [sideloadly.io](https://sideloadly.io)에서 Sideloadly를 받아 설치합니다.

### 3. 아이폰에 설치

1. 아이폰을 USB 케이블로 PC에 연결하고, 아이폰에서 **이 컴퓨터를 신뢰** 를 누릅니다.
2. Sideloadly를 열고 `.ipa` 파일을 창에 끌어다 놓습니다.
3. **Apple ID** 칸에 내 Apple ID 이메일을 넣고 **Start**를 누릅니다. 비밀번호와 2단계 인증 코드를 물으면 입력합니다.
   (부담되면 시험용 Apple ID를 새로 만들어 써도 됩니다.)
4. 아이폰에서 **설정 → 일반 → VPN 및 기기 관리** → 내 Apple ID → **신뢰**를 누릅니다.
5. iOS 16 이상이면 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시동합니다.
6. 홈 화면의 **사진 가계부** 아이콘을 눌러 실행합니다. 처음 촬영·사진 불러오기 때 권한을 물으면 허용합니다.

### 알아 둘 점

- 무료 Apple ID로 설치한 앱은 **7일 뒤 열리지 않습니다.** 그 전에 Sideloadly로 같은 파일을 다시 설치하면
  기간이 다시 7일로 늘어나고, **앱 안의 가계부 데이터는 그대로 남습니다.** (앱을 지우면 데이터도 지워집니다.)
- 새 버전을 설치할 때도 같은 방법으로 덮어쓰면 데이터가 유지됩니다.
- 무료 Apple ID는 이런 식으로 동시에 3개 앱까지만 설치할 수 있습니다.

<br>

## ② 나중에 TestFlight로 넘어가려면

1. [Apple Developer Program](https://developer.apple.com/kr/programs/)에 가입합니다 (연 99달러, 승인까지 하루~이틀).
2. App Store Connect에서 앱(번들 ID `com.haneul.budgetApp`)을 등록하고 API 키를 만듭니다.
3. GitHub Actions 또는 Codemagic(매달 무료 500분 Mac 빌드)에 키를 넣으면, 코드를 올릴 때마다
   TestFlight로 자동 업로드되게 설정할 수 있습니다. 이 단계가 필요해지면 말해 주세요.

# AI 자동 분류 켜기 (API 키 직접 넣기)

서버 없이, 앱에 Anthropic API 키를 넣어서 바로 쓰는 방법입니다. 나 혼자 시험할 때 쓰는 방식이에요.
(앱을 다른 사람에게 나눠 주거나 스토어에 올릴 때는 [서버 방식](../proxy/README.md)으로 바꿔야 합니다)

> Claude Pro/Max 같은 claude.ai 구독은 앱에서 쓸 수 없어서, **API 키를 따로** 만들어야 합니다.
> Claude Haiku 5.5는 아주 저렴해서 영수증 한 장에 1원도 들지 않습니다.

<br>

## 1. API 키 만들기 (PC나 폰 브라우저에서)

1. https://console.anthropic.com 에 가입하고 로그인합니다.
2. **Billing** 에서 카드를 등록하고 크레딧을 충전합니다. 최소 금액(약 $5)이면 아주 오래 씁니다.
3. (권장) **Limits** 에서 월 사용 한도를 $5 정도로 낮게 정해 둡니다. 키가 새어 나가도 그 이상 나가지 않아요.
4. **API Keys** → **Create Key** → 이름은 `budget-app` 처럼 아무거나 → 만들기.
5. `sk-ant-` 로 시작하는 키가 **한 번만** 보입니다. 복사해 둡니다.
   아이폰으로 옮길 때는 PC에서 복사해 메모 앱(iCloud), 카카오톡 나에게 보내기 등으로 보내고, 앱에 넣은 뒤 그 메시지는 지워 주세요.

<br>

## 2. 앱에 넣기

1. 앱 위쪽 바의 **카테고리 관리** → 맨 위 **AI 자동 분류** 를 누릅니다.
2. **API 키 직접** 이 골라진 상태에서 **Anthropic API 키** 칸에 키를 붙여 넣습니다.
3. **연결 확인** → `연결됐어요. "아이스 아메리카노" → 카페/간식` 처럼 나오면 성공입니다.
4. **저장** 을 누릅니다. 카테고리 관리 화면에 `켜짐` 이 보이면 끝.

키는 폰의 안전한 저장소(아이폰 키체인, 안드로이드 암호화 저장소)에만 저장되고, 깃허브나 앱 파일에는 들어가지 않습니다.

<br>

## 쓰는 법

- 영수증을 올리면 키워드로 분류된 품목은 바로 채워지고, 애매한 품목은 잠깐 **"AI가 카테고리를 고르고 있어요"** 가 보인 뒤 채워집니다.
- AI가 고른 항목에는 **"AI가 골랐어요"** 라고 표시됩니다. 마음에 안 들면 눌러서 바꾸면 됩니다.
- 그대로 저장하면 그 품목 이름을 키워드로 기억해서, 다음부터는 AI에 묻지 않고 바로 분류합니다.
- 인터넷이 안 되면 지금처럼 미분류로 남습니다.
- 끄려면 키 칸을 비우고 저장합니다.

<br>

## 문제가 생기면

| 앱에 나오는 말 | 해결 |
|---|---|
| API 키가 올바르지 않아요 | 키 앞뒤가 잘리지 않았는지 확인하고 다시 붙여 넣기. 안 되면 콘솔에서 새 키 만들기 |
| 크레딧이 부족해요 | 콘솔의 **Billing** 에서 충전 |
| Claude에 연결하지 못했어요 | 와이파이·데이터 연결 확인 |
| Claude 서버가 바빠요 | 잠시 뒤 다시 |
